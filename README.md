Project Description

Our group is working on LeetCode Problem #347, Top K Frequent Elements.

The goal is to find the k most frequently occurring distinct numbers in an array.

We plan to compare two approaches:

1. Baseline Solution

Use a hash map to count the frequency of each number.

Sort the distinct numbers by frequency.

Return the top k numbers.

Expected time complexity: O(n log n).

Expected space complexity: O(n).

2. Improved Solution

Use a hash map to count frequencies.

Use bucket sort to find the top k frequent numbers.

Expected time complexity: O(n).

Expected space complexity: O(n).

Proposed Project Twist

Our group is considering extending the problem to find the top k frequent elements across multiple arrays.

The exact requirements and implementation of this variation are still being discussed.
